# User Guide

## Local Execution

To run directly from the project, you can use the task (must execute from the repository root):

```bash
task run
```

or from the repository root:

```bash
task py:sol.mf:run
```

The execution result will be available in `blob/sol.mf`.

## Service Manager

This module is a service and is registered in the system. It is available for management via the REST and CLI interfaces of the Service Manager.
