# Руководство пользователя

## Локальный запуск

Для запуска напрямую из проекта можно воспользоваться задачей (выполнять нужно из корня репозитория):

```bash
task run
```

либо из корня репозитория:

```bash
task py:sol.mf:run
```

Результат выполнения будет доступен в `blob/sol.mf`.

## Service Manager

Данный модуль является сервисом и зарегистрирован в системе. Он доступен для управления через REST и CLI интерфейсы менеджера сервисов.
