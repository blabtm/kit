# Среда разработки

В процессе создания среды разработки преследуются следующие цели:

- быстрая адаптация новых разработчиков
- воспроизводимость среды отладки и развертывания
- поддержка практик и инструментов CI/CD

Основной результат -- контейнер разрабоки (Devcontainer), содержащий в себе все необходимые для работы над проектом инструменты, библиотеки и параментры.

Контейнер разделен на две части. Первая часть по традиции расположена в директории `.devcontainer`. Она используется пользователем при запуске контейнера. В основном, там указаны параметры, необходимые в момент старта контейнера, и пользовательские настройки.

Вторая часть расположена в `.github/.devcontainer` и содержит описание базового образа со всеми необходимыми зависимостями. Он собирается отдельно от первой части (и, в основном, намного раньше).

Для ускорения процессов, базовый образ собирается заранее и хранится в публичном регистре. При каждом обновлении зависимостей, образ автоматически пересобирается и публикуется. Необходимость собирать образ локально -- большая редкость.

## Инструменты

Инструменты, необходимые в процессе разработки (например, `Go`, `Task` или `Vcpkg`), препочтительнее добавлять с помощью специальных модулей -- [Features](https://containers.dev/implementors/features).

Для большого количества инструментов уже существует готовый модуль, который можно найти в [регистре](https://containers.dev/features). Собственные модули, разрабатываемые в соответствии со спецификацией, расположены в подмодуле `.devcontainer/features`.

Используемые в контейнере модули описаны в дискрипторе `.github/.devcontainer/devcontainer.json`.

Некоторые инструменты, в частности библиотеки, удобнее устанавливать классическим способом. Для этих целей приспособлен `.github/.devcontainer/Dockerfile`. В нем содержаться инструкции по установке всех зависимостей, которые нельзя установить через модули. Например, там устанавливаются `vcpkg` и все подконтрольные ему зависимости.
