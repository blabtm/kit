# Настройка окружения

Для работы с проектом требуется только [Docker](https://docs.docker.com/engine/install). Все остальные зависимости включены с контейнер разработки.

Для ускорения процессов, образ контейнера разработки автоматически "пресобирается" и хранится в общедоступном регистре.
