# Менеджер служб

_Менеджер служб_ является основным промежуточным программным обеспечением
[платформы коллайдера VEPP-2000](https://github.com/blabtm/v2k). Он предоставляет унифицированный способ управления
и мониторинга разнородных служб, определенных на платформе.

## REST API

Основной точкой доступа является REST API. Если вы не знаете, что такое REST API, см.
[объяснение Red Hat](https://www.redhat.com/en/topics/api/what-is-a-rest-api).

## CLI

CLI - это удобный способ доступа к Менеджеру служб из оболочки. Рекомендуемый способ установки:

```bash
go install github.com/blabtm/v2k/platform/sm@v0.0.0
```

По умолчанию, CLI будет действовать как REST-клиент к существующему экземпляру Менеджера служб. В случае, если у вас
нет запущенного экземпляра, вы можете использовать CLI в отдельном режиме.

Вы можете увидеть все доступные команды, их описание и флаги с:

```bash
sm help
```
