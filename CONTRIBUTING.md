# Руководство разработчика

Здесь вы найдёте общие правила и практики, которым следует следовать в качестве разработчика платформы. Подробности о среде разработки для конкретного языка см. в соответствующем каталоге.

## Среда разработки

### Требования

- [Docker Engine](https://docs.docker.com/engine/install/)

### VS Code

Для сборки и запуска контейнера в VS Code необходимо установить соответствующее [расширение](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers).

Откройте VS Code, выполните **Dev Containers: Open Folder in Container** из командной палитры (`F1`) и выберите репозиторий платформы. После этого дождитесь сборки контейнера (это может занять некоторое время, но только при первом запуске).

Для получения дополнительной информации см. [документацию](https://code.visualstudio.com/docs/devcontainers/containers).

### CLI

Если вы предпочитаете что-то другое вместо VS Code или просто хотите запустить контейнер через командную строку, вы можете использовать [CLI](https://github.com/devcontainers/cli).
После завершения установки перейдите в каталог проекта, запустите контейнер и подключитесь к нему:

```bash
devcontainer up
devcontainer exec /bin/bash
```

## Структура проекта

- _platform_ -- промежуточное ПО и инфраструктура платформы
- _config_ -- файлы конфигурации сервисов
- _tools_ -- утилиты сборки и расширения
- _scripts_ -- вспомогательные скрипты
- _schema_ -- схемы межсервисных протоколов
- _native_ -- сервисы на C/C++
- _py_ -- сервисы на Python
- _go_ -- сервисы на Golang
- _jvm_ -- сервисы на Java, Scala, Kotlin и Groovy
